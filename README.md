# 速食街機 FAST FOOD ARCADE

8-bit 橫向清版格鬥（belt-scroll beat 'em up）。你是「速食主義者」，拿著炸雞大錘、薯條劍等速食武器，痛扁「慢食聯盟」：壽司老闆、飯卷老闆、糖葫蘆武僧、珍奶忍者，最後對上 Boss 火鍋大帝。

- 手機可玩（虛擬搖桿 + 按鈕，橫向/直向皆可）
- 線上合作最多 4 人（房間代碼）
- 強烈打擊感：頓幀、螢幕震動、白閃、擊飛連段（juggle）、地裂坑洞、碎片噴飛、牆壁反彈、慢動作、把倒地敵人砸進土裡

## 五種武器（遊戲中隨時 Q / 換武器 切換）

| 武器 | 特色 |
| --- | --- |
| 炸雞大錘 | 慢但毀天滅地。第三下「炸雞隕落」砸地：地裂、全場擊飛、倒地敵人被埋進土裡 |
| 薯條劍 | 快速連刺，第四下「薯條昇龍」挑上天，空中還能繼續戳 |
| 熱狗雙節棍 | 雙面範圍連打，「熱狗旋風」把敵人吊在空中，終結鞭轟飛 |
| 雞塊霰彈槍 | 近距離雞塊爆射、後座力。第三發「雞塊全開」把人轟上牆反彈 |
| 披薩圓鋸 | 丟出去會回來的旋轉鋸，穿透連續切割，接回來補能量 |

另有：**可樂噴射**（衝刺，無敵幀）、**漢堡隕石**（能量滿時的必殺，巨大漢堡從天而降砸出大坑）。

## 執行

```bash
npm install
npm start          # http://localhost:3000
```

- **單人**：直接在瀏覽器開啟即可（純靜態檔也能跑，例如 GitHub Pages 放 `public/`）。
- **連線合作**：需要 Node 伺服器（`npm start`）。所有玩家從同一個伺服器網址開啟遊戲，一人「建立房間」，其他人輸入 4 碼代碼加入（或開 `?room=代碼`）。區域網路請用電腦的 IP，例如 `http://192.168.1.10:3000`；要跨網路可部署到 Render / Railway / Fly 等支援 WebSocket 的服務，`PORT` 環境變數會自動被採用。

## 操作

| 動作 | 鍵盤 | 手機 | 手把 |
| --- | --- | --- | --- |
| 移動 | 方向鍵 / WASD | 左半邊滑動 | 左搖桿 / 十字 |
| 攻擊 | J / Z / Space | 攻擊 | X / A |
| 跳 | K / X | 跳 | B |
| 可樂衝刺 | L / C / Shift | 衝刺 | RB / RT |
| 漢堡隕石 | I / V | 必殺 | Y |
| 換武器 | Q / E / Tab | 換武器 | LB / LT |

## 架構

```
server.js              Node + ws：靜態檔 + 房間制權威模擬（60Hz 模擬、20Hz 快照）
public/sim/            純 JS 模擬核心，瀏覽器與伺服器共用（確定性、無 DOM）
  sim.js               狀態機、打擊判定、擊飛/連段/埋地/牆彈、波次、相機
  weapons.js           五種武器的連段資料（判定框、傷害、擊退、頓幀、動畫關鍵幀）
  enemies.js           敵人 AI 參數與關卡波次
public/js/
  render.js            320×180 像素渲染、背景街道、HUD
  fx.js                粒子、地裂坑、震動、全域頓幀、浮動數字、橫幅
  sprites.js           所有像素圖（字串繪製，無外部素材）
  sfx.js               WebAudio 合成 8-bit 音效與 BGM
  input.js             鍵盤 / 多點觸控 / 手把
  net.js               WebSocket 客戶端與快照插補
  main.js              選單、離線 / 連線主迴圈
test/sim.test.js       無頭模擬測試（五把武器各打通一關）
```
